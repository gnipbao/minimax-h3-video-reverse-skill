# 从疑点到可查看证据

原创教学演练，不包含实际用户素材；下列观察结果为设定，不能拿来登记实际媒体 reviewed。

## 场景与选择

沿用 [蓝色产品布套](05-view-and-effect.md) 的教学设定。全局小格联系表只让人看出“两手拉动一块蓝色布料”。上一镜是正面，当前镜的表面方向和开口不够清楚。

| 当前问题 | 应采取的动作 | 不足以结案的动作 |
| --- | --- | --- |
| 是前面还是背面，是否同一个开口 | 打开当前镜的原尺寸初态与末态，识别表面标记及轮廓 | 继续从小格猜，或只在其他时刻多抽同尺寸图 |
| 布片遮住了标签还是标签消失了 | 查看初态到结果的邻接序列，保留手、布片和标签的空间关系 | 只看两张端点，补出撕掉标签的动作 |
| 下一镜正面完整，是转动还是剪辑恢复 | 扩大到前后交接区间 | 只看展开末态，编写转身或自动卷回 |

返图后必须实际打开生成的图片；没有视觉能力则仍是待查看。需要密集帧也要控制页数与单元大小，标签写在图外。缩略图可导航，判断细小结构仍回原尺寸帧；局部裁切旁保留整帧位置，避免失去手与物件关系。

## 观察回执与双向修订

可用一条简短记录，无需增加大型生产文档：

```text
问题：当前镜和正面镜展示的是同一个表面吗？展开新增了什么？
选取：当前镜初/中/末态的原尺寸帧，并补前后切镜邻接帧。
实际查看：记录真实工具返回的文件、证据ID与时间；未打开的不列入。
可见发现：教学设定中，当前镜是背面；标签两侧从露出变为覆盖，系带开口由矮变长。
观看作用（解释）：让观众看清背部展开与贴合，补足前视没有显示的结构。
回写：修订initial/action/ending及整体复述，再核对静态、Motion和最终H3对应句。
未决项：开口内被遮住的结构保持未知，不靠产品常识补齐。
```

压缩成“展示弹性”会丢失本镜新增的可见信息。保留“背面、两侧覆盖、中央开口展开”这几个决定性关系后，再删去无关的重复形容词。整体理解和局部发现应相互修订；“为了展示弹性”这一解释不能证明源里发生了回弹。

## 给用户的返图

用户指出视觉遗漏时，展示一张三格源帧对照：初态、关键中间态、截止态。每格带实际源时间，文字只解释图中可见差异；保留原帧链接。这张图用来检查理解，I2V的Picture1仍取该镜单独初帧。

如果用户只要文本，内部照常查看证据，最终保持文本交付。不要强制附全片几十张图，也不要要求用户重复批准已经确定的修订。

## 反测与控制

1. 只拿到联系表路径，未返回像素：不能声称看过；打开图后才记录查看范围。
2. 文字或微小部件不清：升级空间尺度；不能用更多低分辨率时刻替代。
3. 接触和遮挡顺序不清：升级时间尺度并保留前后交接；不能只放大单帧。
4. 多次查看仍无法区分两种解释：标 uncertain，最终Prompt不采纳未知机制。
5. 单镜静止、结构在当前帧已清楚：直接使用充分证据，不为套流程制造背面、形变或大量重复抽帧。

实际行为验证应记录原问题、读取尺度如何改变、真正看过的证据、事实和文案如何修订。自动测试只核对图片与索引的构建、哈希、时间和状态；不能证明视觉判断正确。
